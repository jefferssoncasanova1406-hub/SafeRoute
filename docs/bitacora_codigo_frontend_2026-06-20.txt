2. PROBLEMA PRINCIPAL ENCONTRADO
El frontend de rutas seguia conectado a un flujo viejo:
- pedia coordenadas manuales
- consumia un endpoint anterior
- esperaba un contrato de respuesta distinto
- no dibujaba rutas reales del backend nuevo
- no mostraba instrucciones giro a giro del endpoint de evaluacion

3. CAMBIOS IMPORTANTES HECHOS

3.1. Ajuste del contrato de rutas
Archivos:
- frontend/src/app/core/services/route.service.ts
- frontend/src/app/features/routes/models/route-request.model.ts
- frontend/src/app/features/routes/models/route-response.model.ts

Que se hizo:
- Se cambio el endpoint del frontend a POST /api/routes/evaluate
- Se reemplazo el request viejo por:
  - origin
  - destination
  - transportMode
- Se reemplazo el response viejo por el contrato real del backend:
  - originResolved
  - destinationResolved
  - transportMode
  - departureTime
  - routes[]
  - geometry
  - steps

Como se soluciono:
- Se alinearon los modelos TypeScript con los DTO reales del backend.
- Se renombro el metodo del servicio a evaluateRoute() para reflejar el caso de uso correcto.

3.4. Reduccion del peso del bundle inicial
Archivo:
- frontend/src/app/app.routes.ts

Problema:
- La inclusion de mapbox-gl empujaba demasiado el bundle inicial.

Solucion:
- La ruta /app/rutas se movio a carga diferida con loadComponent().

Resultado:
- El bundle inicial bajo y el build volvio a pasar sin exceder el presupuesto principal.

3.5. Centralizacion de configuracion de runtime
Archivos:
- frontend/src/app/core/config/runtime-config.ts
- frontend/src/app/core/services/auth.service.ts
- frontend/src/app/core/services/risk-zone.service.ts
- frontend/src/app/core/services/route.service.ts
- frontend/src/app/features/routes/pages/route-calculate/route-calculate.ts

Problema:
- El frontend tenia URLs de backend hardcodeadas en varios servicios.
- El token publico del mapa estaba embebido dentro del componente.

Solucion:
- Se creo un punto unico de configuracion:
  - apiBaseUrl
  - mapboxPublicToken
- Se dejo soporte para override en runtime con window.__SAFEROUTE_CONFIG__
- Los servicios y el mapa ahora consumen esa config central.

Archivo:
